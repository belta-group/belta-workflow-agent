## このサイトは何のためのもの？

**結論から言うと** — このサイトは、**BELTA ワークフローエージェント**（社内向けの業務アシスタント）を、迷わず使い始めて毎日活用するための**利用者向けガイド**です。

「アシスタント」とは、**Notion・Slack・GitHub・Google Drive の 4 つのアプリを使い分ける、あなた専用の秘書**のこと。これまで自分で「どのアプリを開いて、どこに何を入力するか」を考えていた作業を、話しかけるだけで肩代わりしてくれます。

導入から初回設定、日々の使い方、安全のための注意点までを、順番にまとめています。

## どこから読めばいい？

初めての方は、次の順に読み進めれば迷いません。

1. **[概要](/guide/)** — そもそも何をしてくれるのか、ざっくりつかむ。
2. **[導入手順（5 分セットアップ）](/guide/getting-started)** — 実際に入れて、使える状態にする。
3. **[基本的な使い方](/guide/usage)** — 毎日の使い方のイメージをつかむ。

::: warning 共有するときの注意（社外秘を含みます）
このガイドや、アシスタントが扱う情報には**社外秘**が含まれます。このサイトの URL を共有する範囲や公開設定にご注意ください。また、あなた専用の個人データ（パソコン内の `~/.belta/` フォルダ）は、リポジトリに保存（コミット）しないでください。
:::
