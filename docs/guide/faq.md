# トラブルシューティング / FAQ

困ったときの確認事項をまとめています。OAuth 接続まわりは **[4 ツール OAuth 接続](/guide/oauth-setup#うまくいかないときは)** も参照してください。

## セットアップ

### 初回セットアップの案内が出ません

プラグインを入れた時点で**すでに開いていたセッションでは発火しません**。**新しいセッションを開始**してください。それでも出ない場合は手動で実行できます。

```
/workflow-setup
```

### もう一度セットアップをやり直したい

`~/.belta/.onboarded` があると「セットアップ済み」と判断されます。やり直す場合は `/workflow-setup` を実行し、やり直したい旨を伝えてください。

### セットアップの途中で別の用件を頼みたい

そのまま別の用件を頼んで構いません。`~/.belta/.onboarded` が作成されるまでは、次回のセッション開始時に再び案内されます（やり残しの自己修復）。

## OAuth 接続

### `/mcp` にツールが出てこない

1. claude.ai → Settings → Connectors で対象サービスが「接続済み」か確認。
2. Claude Code を再起動して再読み込み。
3. プランが **Max / Team / Enterprise** か確認（Connector 利用条件）。

### `gh auth status` が `Logged in` になりません

`gh auth logout` してから `gh auth login --web` をやり直してください。ブラウザが開かない場合は、表示された URL を手動でブラウザに貼り、ワンタイムコードを入力します。

### 会社プロキシ下で認可が失敗します

claude.ai・github.com への到達性をプロキシ／ファイアウォール設定とあわせて情シスに確認してください。

### ツール名のプレフィックスが資料と違います

`mcp__claude_ai_Notion__*` などのプレフィックスは Connector の構成で変わります。**サービス名で該当ツールが見えていれば接続成功**です。PII 検知フックはプレフィックスに依存しないため、機密遮断はこの違いに関わらず機能します。

## 使い方

### 思っていたのと違うツールに振り分けられました

発話の内容・キーワードから判断しているため、意図と異なる場合があります。「Slack ではなく Notion にして」のように指示し直してください。同じ訂正が続くと、[自動ルール化](/guide/personalization#_1-自動ルール化-rule-learning)で恒久的に反映する提案が出ることがあります。

### 書き込みのたびに確認が出るのは仕様ですか

はい。送信・作成・更新・PR 作成などの**書き込み系は毎回確認**が入ります（[permission の ask 分類](/guide/security#l2-permission-allowlist)）。読み取り系は確認なしで実行されます。

### 操作がブロックされました

2 つの可能性があります。

- **PII / 機密の検知**（L1）: マイナンバー・カード番号・「社外秘」ラベルなどを含んだまま外部送信しようとした。該当箇所を除いて送り直してください。
- **deny 分類**（L2）: `rm -rf` / `git push --force` / `.env` の読み取りなど、破壊的・危険な操作。これらは構造的に禁止されています。

詳細は **[セキュリティと権限](/guide/security)** を参照してください。

### ブラウザ操作が必要と言われました

ブラウザ自動化スキルは本体に含まれていません。必要なときだけ個別にインストールしてください。

```
/plugin install browse@<repo>
```

Notion / Slack / GitHub / Google Drive で完結する範囲であれば、ブラウザなしで進められます。

## パーソナライズ

### 勝手にルールやエージェントが増えませんか

増えません。ルール化・エージェント化・スキル導入は、いずれも**あなたの承認を取ってから**蓄積されます。拒否すれば見送られ、しつこく再提案されません（連続で却下すると一定期間提案が止まります）。

### 作られた専用エージェントを消したい

`~/.claude/agents/<slug>.md` を削除すれば呼び出し対象から外れます。起動時の健全性チェックで検知され、`AGENTS.md` に `deleted_at` が記録されます。

### Windows でも同じように動きますか

はい。フック・補助スクリプトは Claude Code 同梱の Node.js で実装されており、OS 依存コマンドに頼りません。symlink ができない環境では自動的にコピーへフォールバックします。

## データ・プライバシー

### 自分のプロフィールやメモはどこに保存されますか

すべて `~/.belta/` 配下（POSIX: `$HOME` / Windows: `%USERPROFILE%`）に保存されます。`.gitignore` で除外されており、**リポジトリにはコミットされません**。

### 認証情報はローカルに平文で保存されますか

されません。Notion / Slack / Google Drive は claude.ai 側 OAuth 保管庫、GitHub は OS 標準資格情報ストアにトークンが保管されます。

## それでも解決しないとき

情報システム部の推進担当へ、症状と再現手順を添えて連絡してください。機密情報そのものは連絡に含めないでください。
