# コマンド一覧

このページは、このアシスタント（秘書）に最初から備わっている **コマンド（合図の言葉）の一覧**です。読み終えると、「どんなときに、どの合図を打てばよいか」がひと目で分かります。

::: tip 結論
ふだんは **`/workflow` だけ** 覚えておけば大丈夫です。残りは「初期設定」「定期実行」「育成アバター」「振り返り」と、**目的がはっきりしたときだけ**使う特別な合図です。
:::

コマンドとは、頭に `/`（スラッシュ）を付けて打つ「秘書への合図」です。ふつうの頼みごと（発話）と違い、決まった作業を一発で呼び出せます。

## まず覚える 1 つ

| コマンド | これは何をする合図か |
| --- | --- |
| **`/workflow`** | 秘書を呼び出す基本の合図。あなたの言葉を読み取り、Notion・Slack・GitHub・Google Drive のうち最適なアプリへ自動で振り分けます。初回はかんたんな初期設定（5 問）から始まります。 |

迷ったらこれを打つ、で構いません。詳しくは [基本的な使い方](/guide/usage) を参照してください。

## 目的がはっきりしたときに使う合図

::: info このセクションの読み方
それぞれ「いつ使うか」を太字で先に書いています。今すぐ全部覚える必要はありません。必要になったときに戻ってきてください。
:::

| コマンド | 引数（オプション） | いつ・何のために使うか |
| --- | --- | --- |
| **`/workflow-setup`** | （なし） | **いちばん最初の 1 回だけ。** あなた専用の執務室フォルダを作り、氏名・部署・メールの登録と、4 つのアプリの「許可」ボタンでの接続（OAuth）を行います。所要およそ 5 分。 |
| **`/workflow-schedule`** | `[定期タスクの説明 / list / remove]` | **「毎朝」「毎週」など、無人で繰り返したい仕事があるとき。** 例：毎朝の TODO 要約、週次の振り返り。自然な言葉で頻度を伝えるだけで、定期ジョブとして登録・一覧・削除できます。 |
| **`/avatar`** | `[--publish] [--days N] / setup` | **育てている相棒アバターの成長を見たいとき。** 使い込むほど貯まる活動データからレベル・ステータス・実績バッジを再計算し、ダッシュボードを更新します。`setup` で名前・画像を設定、`--publish` で匿名の数値だけを社外向けに公開（既定オフ）。 |
| **`/insights`** | `[--days N] [--topic <語>]` | **「最近なにをしていたっけ」と振り返りたいとき。** 過去の作業メモを横断して、直近の動き・繰り返しているテーマ・抜け漏れを要約します。`--days` で期間、`--topic` で話題をしぼれます。 |
| **`/report`** | `[daily｜weekly｜monthly]`（略 d／w／m） | **「成長を振り返って、次にやること・学ぶことまで知りたい」とき。** 日報・週報・月報として、(1) 何をしたか (2) 成長した点 (3) 次のアクション (4) 学ぶとよいこと、を作業メモとアバターの成長記録からまとめます。省略すると日報。 |

::: tip 引数（オプション）とは
コマンドの後ろに付ける「細かい注文」のことです。たとえば `/insights --days 7` なら「直近 7 日分で振り返って」という意味になります。付けなければ、ちょうどよい既定値で動きます。
:::

## よくある使い分け

- **今日から使い始める** → まず `/workflow-setup`（初期設定）、次から `/workflow`。
- **毎日のルーティンを自動化したい** → `/workflow-schedule`。
- **自分の働きぶり・成長を眺めたい** → `/avatar`（成長の見える化）／`/insights`（過去の振り返り）。
- **成長を振り返り、次の一手や学ぶことまで知りたい** → `/report`（日報・週報・月報）。`/insights` が「過去に何をしたか」中心なのに対し、`/report` は**次のアクション・学習提案まで**出します。

::: info 補足
ここに挙げたのは、このアシスタントに**最初から備わっている標準コマンド**です。使い込むうちに、あなた専用のスキルや担当エージェントが増えていくことがあります（[パーソナライズ機能](/guide/personalization) を参照）。
:::
