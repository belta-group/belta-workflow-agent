# 基本的な使い方

このページでは、**毎日の業務でこのアシスタント（エージェント）にどう話しかければよいか**を説明します。読み終えると、Notion・Slack・GitHub・Google Drive の使い分けを一切意識せずに、ふだんの言葉で頼みごとをこなせるようになります。

::: tip 結論
このアシスタントは「**4つのアプリを使い分ける優秀な秘書**」だと思ってください。あなたが話しかけると、秘書が「どのアプリを開いて、どこに書くか」を代わりに判断してくれます。あなたは、人に頼むときと同じように、ふつうに話しかけるだけで大丈夫です。
:::

セットアップが終わったら、あとは **普通に話しかけるだけ**です。あなたが話しかける言葉（発話）の内容を秘書が読み取り、いちばん合ったアプリへ自動で振り分けます。アプリごとの違いを覚える必要はありません。

## 起動

まず **あなた専用の執務室（`~/my-agent` フォルダ）を Claude Code で開いてから**、秘書に「これから仕事をお願いします」と声をかけます。それが次のコマンドです（秘書はこの執務室の中でだけ働くので、別のフォルダでは呼び出せません）。

```
/workflow
```

このコマンドを打つと、秘書はまず**あなたのプロフィール**（あなたのPC内の個人フォルダ `~/.belta/profile.md` に保存されています）に目を通します。そこには、あなたの部署・扱う情報の機密度・主な仕事内容が書かれており、それを踏まえたうえで仕事モードに入ります。最初に身上書きを読んでから働き出す秘書、とイメージしてください。

## 発話 → 4 ツール分岐

::: tip このセクションの要点
あなたの言葉づかいやキーワードから、秘書が**行き先のアプリを自動で選んでくれます**（ツール分岐）。どれを選ぶか、あなたが指定する必要はありません。
:::

たとえば「メモにまとめて」と言えば Notion、「みんなに知らせて」と言えば Slack、というように、頼みごとの中身を見て担当アプリが決まります。目安は次のとおりです。

| 担当アプリ | こんな頼みごとのとき | 言い方の例 |
| --- | --- | --- |
| **Notion**（メモ・資料の置き場） | メモ整理、議事録、やること（TODO）、ナレッジのまとめ | 「来週の打ち合わせメモを整理して」 |
| **Slack**（社内のチャット） | 共有、連絡、お知らせ、リマインド、過去のやりとりを読む | 「この件をインフラチームに共有して」 |
| **GitHub**（開発の作業記録） | 開発の進捗・変更内容・リリース状況の確認 | 「先週の変更をまとめて」 |
| **Google Drive**（共有ファイル倉庫） | ファイル探し、PDF・議事録・資料の取り込み | 「議事録のPDFを取り込んで」 |

### 発話例

実際の言い方と、そのとき秘書が何をするかの例です。

```
> 来週の定例ミーティングのメモを整理して、Notion にまとめておいて
→ Notion にページを作成（書き込む前に、内容を要約して一声確認）

> さっきの障害対応の経緯を、インフラチームの Slack に共有して
→ Slack に投稿（送る前に、内容と送り先チャンネルを一声確認）

> 先週仕上がった開発の変更を、一覧で見せて
→ GitHub 用の小さな道具（gh）で変更履歴を取得（見るだけなのでそのまま実行）

> 共有ドライブにある来期予算の資料を探して、要点を教えて
→ Google Drive を検索して読み取り（見るだけなのでそのまま実行）
```

## 複数ツールにまたがる依頼

1つの頼みごとが複数のアプリにまたがってもかまいません。秘書が**段取りを決めて、1つずつ順番に**こなし、各ステップの結果をそのつど報告します。「議事録をまとめてから、その要点をみんなに知らせて」のような、人に頼むのと同じ言い方でOKです。

```
> 今日の議事録を Notion にまとめて、要点をチームの Slack にも共有して
→ ① Notion にページ作成 → ② その要点を Slack に投稿（各ステップで一声確認）
```

## 読み取りと書き込みの扱いの違い

::: tip 結論
**見るだけの用事はそのまま、送る・作る用事は念のため一声かけてから実行**します。
:::

これは慎重な秘書の振る舞いと同じです。資料を「探す・読む」だけなら勝手に進めますが、「送る・作る・書き換える」ときは、取り返しがつかないこともあるので、必ず内容を要約して見せ、あなたの確認を取ってから動きます。

| 種別 | 例 | 秘書の振る舞い |
| --- | --- | --- |
| **読み取り系**（見るだけ） | 検索、一覧、閲覧 | 確認なしでそのまま実行 |
| **書き込み系**（送る・作る） | 送信、作成、更新、変更の登録 | **実行前に内容を要約して確認**を取る |

::: warning 注意
特に**社外秘・極秘**の内容を Slack の公開チャンネルや社外へ送ろうとするときは、必ず確認が入ります。詳しい仕組みは **[セキュリティと権限](/guide/security)** を参照してください。
:::

## 自動で記録されること

::: info このセクションの要点
あなたが頼まなくても、その日の**決めごと・気づき・やること**を、秘書が日付ごとのメモとして自動で残してくれます。保存先は、あなたのPC内の個人フォルダ（`~/.belta/`）です。
:::

優秀な秘書が業務日誌を勝手につけてくれるようなものです。あとから「あの日なにを決めたっけ」と振り返れます。保存先は次のとおりです。

- 決めごと・気づき・記録 → `~/.belta/notes/YYYY-MM-DD.md`
- ちょっとしたメモ・受信箱 → `~/.belta/inbox/YYYY-MM-DD.md`
- やること（TODO） → `~/.belta/todos/YYYY-MM-DD.md`

同じ日付のファイルがあれば**追記**され、すでにある記録が消されることはありません。これらの記録は、後で紹介する[パーソナライズ機能](/guide/personalization)が「いつも繰り返している作業」を見つけ出す手がかりにもなります。

## ブラウザ操作が必要なとき

Web サイトを見て回って情報を集めたり、画面を操作したり——つまり **Claude が代わりにブラウザを操作する機能**（ブラウザ自動化）が必要な頼みごともあります。この機能は秘書の標準装備には含まれていないため、入っていない場合はその旨を案内します。全員が使う機能ではないので、あえて本体と切り離してあります。

必要になったら、次のコマンドで追加できます（道具箱に新しい道具を1つ足すイメージです）。

```
/plugin install browse@<repo>
```

追加したら、もう一度同じ頼みごとをしてください。なお、Notion・Slack・GitHub・Google Drive の中だけで済む用事であれば、ブラウザの追加なしでそのまま進められます。
