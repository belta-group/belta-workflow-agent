# 概要

**結論から言うと** — Belta ワークフローエージェントは、**Notion・Slack・GitHub・Google Drive の 4 つのアプリを使い分ける、あなた専用の秘書**です。あなたは「どのアプリを開くか」を考えなくてよくなります。

::: tip ひとことイメージ
優秀な秘書に「これやっといて」と話しかける感覚です。秘書（このアシスタント）が中身を読み取り、ふさわしいアプリを自分で選んで処理します。あなたの窓口は、この秘書ひとつだけ。
:::

使い始めるときは `/workflow` と打つか、そのまま話しかけるだけ。秘書はあなたの部署・主な仕事・扱う情報の重要度を覚えていて、それを踏まえて動きます。

## 何ができるか

話しかけた内容に応じて、行き先のアプリが自動で選ばれます。代表的なのは次の 4 つです。

| こう話しかけると | 秘書がやること |
| --- | --- |
| 「議事録を整理して」 | メモアプリ（Notion）にまとめる |
| 「チームに共有して」 | チャット（Slack）に投稿する |
| 「先週の作業をまとめて」 | 開発記録（GitHub）から要約する |
| 「資料 PDF を取り込んで」 | ファイル置き場（Google Drive）から読み込む |

このほか、次のこともできます。

- **複数のアプリにまたがる頼みごと** — 「議事録を Notion にまとめて、要点を Slack にも共有して」のような依頼も、1 つずつ順番に実行します。
- **使うほどあなた専用に育つ** — よく出す指示や、繰り返す種類の仕事を覚えます。ただし覚えるのは、あなたが**承認したものだけ**です（詳しくは[パーソナライズ機能](/guide/personalization)）。
- **Notion のデータベース設計の相談** — 自部署向けの表（データベース）づくりを、設計の知識を持つ専門モードが手伝います。

## 対象利用者

- **Belta の社員**。
- **Claude Code を業務で使う方**。エンジニアでなくても使えます。必要なのは、各アプリで「許可」ボタンを押すこと、そして GitHub を使う場合に `gh auth login --web` という 1 行のコマンドを 1 回実行することだけです。

::: info いまは「お試し中」の段階です
本アシスタントは現在、社内での試用段階です。情シスの数名が実際に使って動作を確かめ、経営会議に出す「どれだけ仕事が楽になったか」のデータを集めています。機能や説明は随時更新されます。
:::

## 前提環境

**結論** — 必要なのは「Claude Code」「claude.ai の対象プラン」の 2 つだけ。GitHub を使う場合の道具（`gh`）は、**未導入でもセットアップが自動で入れてくれます**。

| 項目 | 必要なもの |
| --- | --- |
| Claude Code | インストール済みであること（パソコン版・IDE 拡張のいずれでも可） |
| claude.ai のプラン | **Max / Team / Enterprise** のいずれか（アプリ連携に必要） |
| GitHub 用の道具（`gh`） | GitHub を使う場合に必要。未導入なら、セットアップ中に自動で導入されます（手動なら macOS: `brew install gh` / Windows: `winget install GitHub.cli`） |
| OS | macOS / Windows のどちらでも可 |
| ネットワーク | claude.ai・github.com につながること（社内プロキシ下では情シスに確認） |

## 全体像

あなたの言葉が、どう処理されていくかの流れです。

```
あなたが話しかける
   │
   ▼
秘書（/workflow）が中身を読み取る
   │  内容・キーワード・重要度から判断
   ├─▶ Notion        … メモ / 議事録 / TODO / 表の設計
   ├─▶ Slack         … 共有 / 連絡 / 通知 / リマインド
   ├─▶ GitHub        … PR / Issue / リリース / 開発の状況
   └─▶ Google Drive  … ファイル検索 / PDF・資料の取り込み
   │
   ├─ 機密の見張り（外部に送る直前に、危ないものを止める）
   ├─ 操作ルール（やってよい / 確認する / 禁止 を判定）
   └─ パーソナライズ（あなた好みに少しずつ育てる）
```
