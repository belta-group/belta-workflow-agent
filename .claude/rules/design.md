# デザイン規約（EC-BELTA トンマナ準拠）

このリポジトリが作る**見た目を持つ成果物すべて**（VitePress ドキュメントサイト・生成 HTML ダッシュボード・今後追加する UI 系生成物）は、EC-BELTA ブランドのトンマナに揃えることを必須要件とする。利用者は EC-BELTA を運営する社員であり、見慣れたブランドの「柔らかく親しみやすい」印象（ピンク基調・丸み・淡い面・弱い影）をそのまま踏襲する。

> 適用範囲: `docs/.vitepress/theme/custom.css`、`plugins/workflow/scripts/avatar-render.js`・`token-dashboard.js` 等の**埋め込み CSS/SVG を持つ生成スクリプト**、および今後の HTML/SVG 生成物。プレーンテキスト・Markdown 出力には適用しない。

## 1. 一次資料（正）は EC-BELTA リポジトリの SCSS

デザイントークンの権威ソースは EC-BELTA リポジトリ（`~/belta/ec-belta`）の次の 2 ファイル。**値が食い違ったら SCSS 側を正として本リポジトリを事後同期する**（逆方向に直さない）。

- `app/assets/scss/base/_variables.scss` — カラー・フォント・余白・影・トランジションの変数定義
- `app/assets/scss/utils/_colors.scss` — CSS カスタムプロパティへの展開

形状の参照実装は `app/components/common/BButton/BButton.scss`（ピル型・影・ホバー挙動）。

### 本リポジトリで定義した派生値

| 派生値 | 出自 | 用途 |

### チャートパレット = カテゴリーカラー

グラフ（棒・ドーナツ・凡例）の系列色は EC-BELTA の**カテゴリーカラー**を順に使う。独自のパレットを発明しない。

```
#d76492（Primary）→ #617cc3（美と健康）→ #84bd4a（妊娠中）→ #efbe3a（産後・育児）
→ #f5a279（妊活中）→ #ef988e（自分磨き）→ #4f5978（プレコン）
```

- 「重い・要注意」の強調は `#ce004e`（更年期ケアの濃ピンク）。
- 状態 3 色: 安全 `#84bd4a` ／ 注意 `#e9b83e` ／ 危険 `#e40101`。

## 3. 形状・質感（「柔らかさ」の文法）

ピンクを塗るだけではトンマナにならない。EC-BELTA の柔らかさは**丸み・淡い面・弱い影**の組み合わせで作る。

- **ボタンはピル型**: `border-radius: 5em`。影は `0 6px 6px -3px rgba(0,0,0,.2)`、ホバーで色変化＋わずかな浮き（または EC 流の `opacity: .6`）。
- **角丸の階層**: カード・パネル 16px ＞ コールアウト・コードブロック 12px ＞ 小部品（チップ・バー・セル）8〜10px。直角の箱を作らない。
- **影は弱く**: カードは `0 1px 4px rgba(0,0,0,.06)` 程度。強いドロップシャドウ・グロー禁止。
- **グレー面を使わない**: ニュートラルグレーの面（`#f1f1f1` 等）は淡ピンク面（`#fff6f7` / `#f6e4eb`）に置き換える。
- **トランジション**: 基本 `0.3s ease`、小さな反応は `0.2s ease`。
- 装飾は引き算（doc-writing 規約と同じ精神）。1 要素 1 メッセージ。ピンクの過剰投入で逆に騒がしくしない。

## 4. タイポグラフィ

- フォントスタックは EC-BELTA と同一: `"Noto Sans JP", "Yu Gothic", "游ゴシック", yugothic, "游ゴシック体", "ヒラギノ角ゴ Pro W3", "メイリオ", sans-serif`
- **外部 Web フォントを `@import` / `<link>` しない**（社内 noindex サイト・自己完結 HTML の方針。端末フォントへフォールバックさせる）。
- 本文の行送りは `1.8`（EC-BELTA `$line-height-base`）。

## 5. ダークモードの方針（docs サイトのみ）

EC-BELTA は明背景前提のブランドのため、暗背景に淡ピンクの面をそのまま持ち込まない。

- **面（bg-soft / bg-alt / ボタン地）は VitePress 既定の暗色へ明示リセット**する。
- **アクセントだけピンクを残す**: リンク文字は明ピンク `#e89bb8`、塗りは Primary 維持。
- 生成 HTML ダッシュボードはライトテーマ固定でよい（ダーク対応不要）。

## 6. 罠（Gotchas）— 実際に踏んだもの

- **VitePress のコンポーネント CSS はスコープ属性 `[data-v-…]` 付きで詳細度が高い。** `custom.css` から `.VPFeature` / `.VPButton` 等を同詳細度で上書きしても黙って負ける（ビルドは通るのでスクショで気づくしかない）→ `!important` を付ける。
- **`:root` の変数上書きはソース順で `.dark` 既定より後勝ちになる。** ライト用の面色を `:root` に置いたら、`.dark` ブロックで暗色を明示リセットしないとダークモードの背景が淡ピンクに化ける。
- **VitePress のテーブルは `display:block` ＋ `overflow-x:auto` ＋ `border-collapse:collapse`。** `table` への `border-radius`／`overflow:hidden` は横スクロールと衝突し、`border-collapse:separate` は罫線が二重になる → 角丸は諦め、ヘッダー行とゼブラの面色だけで柔らかくする。
- **グリッドの `固定幅 + 1fr + 固定幅` はコンテナが狭いと `1fr` が 0px に潰れる。** 生成ダッシュボードの横棒グラフが中間幅ウィンドウで丸ごと消えた → バー列は `minmax(48px, 1fr)` で最低幅を保証する。
- **Primary `#d76492` は白背景の小さい文字には薄い。** 文字は `#c44d7d`、塗り・大きな図形は `#d76492` と使い分ける。
- **生成済み成果物（`~/.belta/dashboard.html` 等）はスクリプトを直しても再生成まで古いまま。** 生成スクリプトのデザイン変更後は `/avatar`・`/usage`（または該当スクリプトの直接実行）で再生成して確認する。

## 7. 検証

- **docs サイト**: `cd docs && npm run docs:build` が通ること＋プレビューでライト／ダーク両方をスクリーンショット目視（CSS の詳細度負けはビルドでは検出できない）。
- **生成 HTML**: `node --check` → 実データで再生成 → ブラウザ目視（チャート色・ゲージ・狭幅でのレイアウト崩れ）。
- 機密データ（`~/.belta/` 配下）を確認用サーバーでそのまま配信しない。出力 HTML だけを一時フォルダへコピーして配信し、確認後に削除する。
- セルフレビュー: 「グレー面が残っていないか」「直角の箱がないか」「出自不明の色を増やしていないか」。
